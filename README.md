# 防think指纹探针 v1.0

独立 Chrome／Edge Manifest V3 扩展，基于 Arena 统一探针 3.0.15 的独立副本制作。`AUTO DRAW · v1.0，by hhhhhhhh`；继承 Perkica 工作流，原始第三方版权见 `THIRD_PARTY_NOTICES.md` 和 `LICENSE-ModelTrace`。

## 安装

1. 解压 ZIP，找到内含 `manifest.json` 的 **防think指纹探针v1.0** 文件夹。
2. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`，开启「开发者模式」，点「加载已解压的扩展程序」，选择该文件夹。
3. 打开／刷新 `https://arena.ai/agent` 或 `https://arena.ai/work`；在网页浮窗或扩展工具栏弹窗操作。须自行登录 Arena。无需 Arena 模型助手桌面程序。
4. 若此前装有其他自动抽卡探针，不要同时在同一 Arena 标签页运行它们，以免重复发送或相互干扰。

## 用法与安全边界

- 点击快速识别（一题）／三题核验；自动抽卡可设轮数（1–100）、模式、额度下限。每轮新会话先发暖场随机码，等本轮回复，再问指纹题。
- 识别结果仅在插件面板显示并保存本地摘要；单次识别、自动抽卡及弱匹配追问均不修改会话名称。原有归档策略保持不变。
- 「只保留所选模型」**默认关闭**：必须在可展开的模型列表勾选至少一个模型、主动开启开关，才会按模型归档；非目标候选会补齐三题，仅三条有效、无单题冲突且清晰／接近时归档。弱匹配或证据不足不按模型归档。结果为概率性指纹候选，并非官方确认。
- think 模式默认「**归档并跳过**」：发现本轮推理段后先停止生成，**只有确认归档成功**才继续下一轮。「**保留并跳过**」先确认停止生成，保留该会话再进入下一轮；「**暂停**」停止抽卡，保留当前会话原状。无法确认停止生成／归档、会话变化等均停机。单次探测遇 think 也按该模式处理，但不会自动开启下一轮。
- 归档是 Arena 的会话归档操作；扩展不会按模型删除聊天。不自动点击「Reset session and reload」或退出登录。
- 费用核验属于辅助证据；本地模型库提供 22 个候选并校验文件 SHA-256。设置与摘要保存在该扩展自己的本地存储，不移植桌面宿主的实例模型配置。

本扩展依赖 Arena 当前网页结构和登录状态；网站改版或异常时可能停机。请在非关键会话上先试用，勿将探测结果作为模型身份的确定证明。
